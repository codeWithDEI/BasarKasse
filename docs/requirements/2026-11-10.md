# Event workflow requirements — 10 November 2026

Source: the owner's local `requirement.txt`. English implementation contract;
historical financial records must retain their meaning.

| Requested behavior | Implementation |
| --- | --- |
| Fifty-cent prices, no comma (`5` = 0.50, `25` = 2.50) | Separate article parser/server validation; unchanged cent storage; atomic migration of euro input drafts and obsolete-client gate |
| Event/till login, no selector changes | Account scope, SQL export/read filters, command/outcome guards and personal idle-tablet links |
| Cashier sees its own till's turnover | Assigned-till totals/history/search/full export only |
| Managers can see team PINs | Explicit authorized response; AES-GCM display copy, salted login hash, separate runtime key; no PINs in snapshots/pending commands |
| Count/close tills into a pot before settlement | New-event policy; one atomic counted contribution per till; all opened tills close before payouts |
| Pay seller claims from the pot | Unique seller payout and serialized cash-availability guard |
| Round payout down to ten cents for bazaar | Separate commission/rounding donation/net in persistence, statement and CSV |
| Editable event-specific team | Stable IDs, role/till assignment, PIN reset/disable, revoked sessions and authorization-version guards |
| Venue WLAN; Android/iOS mix | Organizer information recorded; real Internet/device rehearsal still required |
| Open-source license | Owner chose GPL-3.0; GPL-3.0-only declared, third-party notices retained |

Cash-pot assumption: include the entire counted contents, including float; return
float with a documented pool withdrawal. This was stated while the owner's
optional accounting clarification was pending. No unrecorded deduction is made.

Existing events retain their till-funded, cent-exact policy. New events use pool
settlement. No historical sale/payout is repriced or rounded again. Public demo
accounts remain evaluation fixtures; production bootstrap/removal of demo access
and cash-event approval are separate gates.
